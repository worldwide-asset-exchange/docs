# Referencia de API de WAX

Elige la API que se ajuste a las necesidades de tu aplicación.

## APIs

### API de cadena

Para consultar el estado de la cadena y los datos de cuentas, y usar los métodos RPC de transacciones.

- [API de cadena](/apis/chain-api.htm)

### API de AtomicAssets

Para consultar NFTs y otros activos sin recorrer directamente las tablas de la cadena.

- [API de AtomicAssets](/apis/atomic-api.htm)

### API de historial de Hyperion

Para indexar el historial y hacer consultas avanzadas sobre datos históricos.

- [API de historial de Hyperion](/build/api-reference/hyperion-history-api)

### Light API

Para consultas ligeras ofrecidas por cada proveedor que no requieren infraestructura de historial completo.

- [Light API](/build/api-reference/light-api)
