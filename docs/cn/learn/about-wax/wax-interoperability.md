# WAX 的跨链互操作性

WAX 连接不同区块链及其生态系统，支持跨链交易，让收藏者、玩家和创作者可以使用不同链上的数字资产和 NFT。

## Cloud Wallet Bridge

**Cloud Wallet Bridge** 支持在 WAX 与以太坊、BNB Smart Chain、Solana 等区块链之间转移代币和 NFT。用户可以在不同生态系统中交易、收藏和体验游戏。

## Antelope IBC

WAX 集成了 **Antelope IBC**，用于采用 Antelope 技术的区块链之间的通信。IBC 在区块链的基础层运行，无需依赖第三方桥来验证通信。

这使不同的链可以分担处理需求，为更大规模的应用提供支持。

## 互操作性的应用

在不同区块链之间交互，可以促进生态合作，并为游戏、藏品和 DeFi 应用提供更多使用数字资产的方式。Messari 也关注了 WAX 在互操作性方面的工作。
