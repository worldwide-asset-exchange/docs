# 什么是 WAX 区块链？

WAX 是一条名为「万物链」的第一层区块链，支持游戏、数字藏品、代币和模因币等数字商业应用。WAX 注重环保、免交易手续费和可扩展性。

WAX 由 **William E. Quigley** 和 **Jonathan Yantis** 于 2017 年创立，已处理数亿笔交易，并与 **NASCAR**、**AMC**、**Mattel** 和 **Hasbro** 等品牌合作。WAX 还推出了 **vIRLs®**，通过 NFT 将数字资产与实体商品关联。

**WAX Bridge** 支持在不同区块链之间转移 NFT 和代币。My Cloud Wallet 为新用户提供便捷的钱包体验。

除了游戏和藏品，WAX 还支持围绕模因币形成的社区。开发者可以使用 WAX 的工具构建游戏经济系统或发行代币。

**Alien Worlds** 和 **Splinterlands** 等 Web3 游戏也使用 WAX。其**委托权益证明（DPoS）**共识机制支持快速处理交易和扩展网络容量。

[bountyblok](https://bountyblok.io)、[NFTHive](https://nfthive.io) 和 [AtomicHub](https://wax.atomichub.io) 等社区项目为用户提供创建、交易和使用数字资产的工具。
