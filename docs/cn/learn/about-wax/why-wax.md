# 为什么选择 WAX？

WAX 是一条易于使用、可扩展的区块链，为创作者、收藏者和企业提供构建、交易和使用数字资产所需的工具。

## 易于上手

[My Cloud Wallet](https://www.mycloudwallet.com) 让创作者、开发者和初次接触区块链的收藏者都能方便地创建、交易和持有数字资产。

## 快速、可扩展且免交易手续费

WAX 每秒最多可以处理 10,000 笔交易，支持大规模交易、NFT 铸造和游戏经济系统。

## 社区生态

WAX 社区由开发者、艺术家和创业者组成。WAX 团队会举办线上交流活动，也会在 My Cloud Wallet 中展示社区项目。[bountyblok](https://bountyblok.io)、[NFTHive](https://nfthive.io) 和 [AtomicHub](https://wax.atomichub.io) 都是其中的例子。

## 应用实例

NASCAR、AMC、Mattel 和 FUNKO 等品牌使用 WAX 发行数字藏品。vIRLs® 技术将数字资产与实体商品关联，也可用于游戏或其他代币化体验。

## 跨链互操作

WAX Bridge 支持在不同链上转移代币和 NFT。WAX 的模因币生态也为不同类型的社区提供了参与方式。

## 为什么选择 WAX？

WAX 已处理数亿笔交易，并提供从开发游戏到创建代币所需的工具。访问 [WAX 官网](https://wax.io) 了解更多。

::: tip 说明
示例和数据来自实际应用和统计。WAX 生态仍在发展，请访问 [WAX 官网](https://wax.io) 和官方社区渠道了解最新信息。
:::
