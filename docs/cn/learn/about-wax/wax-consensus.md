# WAX 区块链如何运作？

## 共识机制

WAX 区块链采用**委托权益证明（DPoS）**，以快速、安全、节能的方式处理交易。

## 委托权益证明（DPoS）

传统的工作量证明（PoW）依赖高能耗的挖矿，WAX 则采用 DPoS：

- **质押与资源**：持有者可以质押 WAXP，获得 CPU 和 NET 资源来处理交易。
- **社区治理**：WAXP 持有者可投票选出区块生产者（BP），由他们验证交易、生成区块并维护链的完整性。

## DPoS 的特点

- **可扩展性**：每秒可以处理数千笔交易，为网络负载高峰提供容量。
- **安全性**：较短的区块确认时间有助于提高网络可靠性。
- **能效**：DPoS 无需挖矿，可降低网络运行的能耗。

这一共识机制为游戏、藏品、DeFi 和模因币等应用提供支持，同时让社区能够参与治理。
