# 什么是 WAXP 代币？

WAXP 是 WAX 区块链的原生代币，可用于 NFT 交易、质押和参与治理。

## WAXP 有哪些用途？

- **支持交易**：WAXP 为市场、交易和 dApp 活动提供支持。
- **质押与奖励**：质押 WAXP 可帮助维护网络并获得奖励。
- **参与治理**：WAXP 持有者可以参与区块生产者选举、升级和社区提案的投票。

## WAXP 持有者的权益

- **参与奖励**：通过质押或投票参与网络，可获得 WAXP 奖励。
- **社区决策**：持有者可以参与去中心化决策，使网络的发展更符合社区需求。

## 探索 WAX 生态

WAXP 将用户与 WAX 上的游戏、数字藏品和代币社区联系起来。更多信息请阅读 [WAX 代币经济文章](https://medium.com/wax-io/coming-to-wax-a-new-wax-tokenomic-model-cd0616a069e9)。
