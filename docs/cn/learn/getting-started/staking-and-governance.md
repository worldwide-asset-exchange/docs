# 质押与治理

WAXP 除了用于应用操作和资产转账，也用于参与 WAX 网络。

## 质押的作用

用户可以质押 WAXP，通过 WAX 钱包或服务参与网络及其奖励机制。与日常交易使用的 PowerUp 相比，质押通常是较长期的参与方式。

## WAX 治理

WAX 使用委托权益证明。代币持有者可以参与治理，从而影响网络运作和区块生产者的选举。

- 持有和质押 WAXP 是参与网络治理的方式。
- 参与治理与日常签署交易或使用应用属于不同的操作。

## PowerUp 与质押

- **PowerUp** 为账户操作即时提供执行资源。
- **质押** 用于较长期地参与网络，并规划资源或参与治理。

实际操作取决于所使用的钱包或界面。

## 质押之前

- 了解钱包及其恢复方式。
- 确定如何跟踪账户状态。
- 使用可信的界面，并核对要签署的操作。
